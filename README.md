# Friction Force Game — 마찰력 미로

중학교 과학 1 · 힘의 작용 · 마찰력 복습 게임

**플레이:** https://moonclipse-t.github.io/Friction-Force-Game/

- 처음에 내 캐릭터 만들기: 남자·여자, 피부색, 머리 모양 15가지·머리 색, 수염, 안경, 옷 스타일 7가지·색, 아무거나 버튼 (기기에 저장, 홈에서 다시 꾸미기)
- 상자를 밀어 도착점에 딱 멈추게 하는 3D 퍼즐 (얼음 · 모래 · 사포 · 구멍 · 짐)
- 단계를 깨면 마찰력 문제 2개 — 둘 다 맞혀야 다음 단계가 열린다
- 키보드(방향키 · 스페이스) 또는 터치 버튼으로 플레이
